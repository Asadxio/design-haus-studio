Connect your studio database

The DESIGN HAUS admin control room is built and ready, but requires your live Supabase project configuration to enable authenticated admin access, dynamic database management and storage.

  1. Create a Supabase project at supabase.com.
  2. Open the Supabase SQL Editor and execute supabase/schema.sql.
  3. Open config.js in this website directory and insert your Project URL and anon key.
  4. Create your admin user in Supabase Authentication, then link their user UUID into the admin_users table.

See README.md for step-by-step setup details.
